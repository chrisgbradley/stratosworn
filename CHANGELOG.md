# Changelog

Every mod add, config change, and why. Newest first.

## 0.1.0 (in progress)

- 2026-09-10: Retests after the ModernFix fix. Green and back in: Ars Elemancy 1.17, Create Mechanical Extruder 2.2.2, plus ProbeJS 8.0.3 (client). Still out: Simulated Copycats, which now fails differently and genuinely (Create `AllAdvancements` hits an unbound `create:chocolate_bucket` at server boot).
- 2026-09-10: Root cause found for a run of client crashes. ModernFix's `mixin.feature.registry_event_progress` (a loading-screen progress bar over NeoForge's `GameData.postWithProgressBar`) makes Create's Registrate throw "Found unused register callbacks" during client mod loading when certain addons are present. Shipped `pack/config/modernfix-mixins.properties` with it off; FTB Quests then loads clean. Create Mechanical Extruder, Simulated Copycats and Ars Elemancy were rejected on this false signal and are being retested. Details in `docs/DEV_CLIENT_REGISTRATE.md`.
- 2026-09-10: Phase 5 mods in: FTB Library, FTB Teams, FTB Quests, all from CurseForge (no Modrinth builds for 1.21.1 NeoForge). Ars Elemental 0.7.10.1 also from CurseForge, which unblocks the Four Elements chapters.
- 2026-09-10: Foundry & Grimoire chain complete. Green and committed: Create Connected 1.3.3, Create Encased 1.9.0, Not Enough Glyphs 4.6.1, SSRD 1.8.6 (client-only; it requires Sodium). Create Connected and Create Encased needed generated loot-table overrides (`scripts/loot-overrides.py`) because both ship compat tables for blocks from mods this pack does not have. Rejected: Simulated Copycats 1.3.2, which crashes the client in Create's Registrate ("Found unused register callbacks") on a clean reproduction while booting the server green, same signature as Create Mechanical Extruder.
- 2026-09-10: Two test-loop bugs found and fixed. Client-only steps now resync the server first: a back-out leaves stale jars in `server/mods`, and the client then bounces with "server sent registries with unknown keys", which reads as a false negative (SSRD was wrongly rejected this way). Back-outs now also remove whatever packwiz auto-added with the mod (a leftover Occultism from Ars Ocultas caused four false rejections).
- 2026-09-10: Foundry & Grimoire chain, first pass. Green: Create Enchantment Industry 2.5.3b, Ars Creo 5.4.0. Rejected with cause: Create Mechanical Extruder (client crash in Create's Registrate: 'unused register callbacks'), Ars Additions 21.3.0 (its manifest declares Minecraft [1.21,1.21.1), a 1.21.0-only build mistagged on Modrinth; breaks Create block registration), Ars Ocultas (requires Occultism, an excluded second magic path). Chain bug: packwiz auto-added Occultism as Ars Ocultas's dependency and the back-out left it behind, so the next four boots (Not Enough Glyphs, Ars Elemancy, SSRD, Simulated Copycats) failed on Occultism's missing deps and were wrongly logged as rejections; those entries are removed and each mod is retested.
